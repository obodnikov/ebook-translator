# Задача: защита от вредных правок сверки

> Status: **предложено, работа не начата**
> Date: 2026-11-22
> Scope: `postprocess.py`, `prompts/verify.md`, `cli.py` (передача абзацев оригинала), тесты,
> `AI_PIPELINE.md`, `CHANGELOG.md`, `README.md`.
> Related rules: [AI_PIPELINE.md](../../AI_PIPELINE.md), [AI_PROVIDER.md](../../AI_PROVIDER.md).
> Предыдущие замеры сверки: §4.5 документа
> [2026-11-01-native-reasoning-on-gateway.md](../design/2026-11-01-native-reasoning-on-gateway.md)
> и сообщение коммита `13027b7`.

---

## 1. Коротко

Сверка (`verify`) — последняя стадия редактуры и единственная, которая видит оригинал. В «A Drop of
Corruption» **не меньше 24 из её 180 правок испортили текст**, в том числе сюжетную загадку и
финальную сцену. Проверки их не заметили: разметка верна, длина та же, слова русские.

Работа делится на три этапа.

| Этап | Что | Платные запросы | Что даёт |
| --- | --- | --- | --- |
| 1 | Три проверки правок сверки в коде | нет | отбрасывают 12 из 24 вредных правок, ни одной из 16 контрольных полезных |
| 2 | Исправить промпт сверки | около 30 кредитов на замер и работа арбитра | убирает вероятную причину, должен сократить и остальные 12 |
| 3 | Решить, нужна ли проверка правок второй моделью | по итогам этапа 2 | только если первых двух этапов мало |

Этапы 1 и 2 независимы. Этап 1 можно выпустить сразу.

## 2. Что случилось

### 2.1 Самое тяжёлое

В книге есть загадка: преступник оставляет записку на древнем языке, герой узнаёт в ней искажённый
девиз и сам переводит её как «Я — Империя».

| Место | До сверки | После сверки |
| --- | --- | --- |
| `ch25_c01`, 28 | …из костного мозга, Te siz imperiya. | …из костного мозга, Я — Империя. |
| `ch25_c01`, 29 | …изречением Императора, Sen sez imperiya, что примерно переводится как Ты — Империя… | …изречением Императора, Ты — Империя… |
| `ch69_c02`, 27 | — Это для вас, когда проснётесь, госпожа | — Чтобы было при ней, когда проснётесь, госпожа |

После первой правки герой читает записку по-русски, а абзацем ниже говорит, что она на древнем
языке. Третья правка — бессмыслица в последней сцене книги.

То же случилось в «The Tainted Cup» (`ch47_c01`, 8): надпись «на древнем, полузабытом языке»
заменена русским «Ты — Империя». Значит, это не случайность одного запуска.

### 2.2 Почему это происходит

Причины установлены чтением промпта и правок. Опытом они не подтверждены: это делает этап 2.

1. **Промпт прямо требует такой порчи.** В [prompts/verify.md](../../prompts/verify.md) версии 4:
   - пункт 4: «Any English word or phrase sitting in the Russian text. Translate it»;
   - правило: «Never copy a word or phrase from the original into your output, and never leave one
     standing».

   Исключения для речи на вымышленном языке нет. Оба правила добавлены в `13027b7` против настоящей
   беды: английских слов, оставшихся в «Bear Head». Убирать их целиком нельзя.
2. **Словарь не спасает.** Обе фразы девиза есть в словаре серии с переводом, равным оригиналу, но
   это противоречит пункту 4. К тому же в примечании записи стоит русский смысл («Старый ханум:
   «Я — Империя»…»), и модель подставила именно его.
3. **Требование соблюдать словарь не мешает синонимам.** «трансплантант» заменён на «прививку»
   в 13 абзацах двух книг.
4. **Род имён сверке не объяснён.** В промпте корректуры есть раздел «Gender of glossary names»,
   у сверки его нет. Она исправила «Мало сказала» на «сказал», хотя в словаре Мало — `f`.
5. **Оригинал подаётся сплошным текстом, а перевод — по номерам.** `collect_chunk_originals`
   соединяет абзацы через перевод строки. Какой абзац оригинала отвечает абзацу N, модель
   отсчитывает сама. Возможно, так и появилась правка `ch69_c02`, 27.

Замер 2026-11-01 (§4.5: «вредных правок 4 из 98») этого показать не мог: в «Bear Head» нет речи на
вымышленном языке, а внесённые английские слова как раз надо было переводить.

## 3. Границы задачи

**Входит:** правки стадии `verify`, её промпт, журнал отброшенных правок.

**Не входит:**

- готовые книги: их EPUB, кэши и рабочие каталоги не меняем;
- точечная починка «A Drop of Corruption»: для 11 фрагментов уже выбран текст до сверки через
  `btrans prefer`, остальное решается отдельно;
- те же проверки для `proofread` и `style`: на них правила дают ложные срабатывания (§5.2);
- перенос меню оглавления, обложка, шлюз.

## 4. Этап 1. Проверки правок в коде

### 4.1 Правила

Все три сравнивают три текста одного абзаца: оригинал, перевод до правки, перевод после неё.
Теги заменены пробелами (`replies._spaced_text`). Точные определения и код — в приложении А.

| Правило | Правка отбрасывается, если | Пример |
| --- | --- | --- |
| **A. Термин латиницей** | исчез термин, перевод которого в словаре записан латиницей | «Te siz imperiya» → «Я — Империя», а также «Te» → «Те» русскими буквами |
| **B. Чужая речь** | исчезла фраза из двух и более латинских слов, которая есть в оригинале и хотя бы наполовину состоит из слов, не встречающихся в английском тексте книги | «Ugasa kavi ki’um livahpam?» → «Угаса кави ки’ум ливахпам?» |
| **C. Термин словаря** | термин из словаря встречается реже, чем до правки и чем в оригинале, а абзац при этом не заменён целиком | «трансплантанты» → «прививки» |

Оговорка в правиле C обязательна. Сверка умеет чинить абзац, где стоит перевод соседнего: в «Bear
Head» `ch21_c03`, 12 и «Foxglove Summer» `ch07_c03`, 7 она заменила абзац целиком. Без порога
сходства 0,5 правило отбросило бы обе починки.

### 4.2 Куда встроить

1. `PostProcessor.process_chunk` получает абзацы оригинала списком, рядом с `original_text`.
   Вызовов два, оба в `cli.py`: стадии внутри `translate` и `_run_postprocess_cmd`. Список уже
   умеет строить `collect_chunk_originals_with_paragraphs`.
2. Проверка стоит рядом с `_damages`, на обоих путях: правки списком (`_apply_patches`) и ответ
   полным текстом. Абзацы оригинала передаются параметром, не полем объекта: один
   `PostProcessor` обслуживает фрагменты параллельно.
3. Работает только для `verify` и только на свежем ответе. Записи кэша не перепроверяются.
4. Отбрасывается только эта правка, абзац остаётся прежним, повторного запроса нет.
5. Словарь книги для правила B строится один раз из оригинала, а не из дерева, в которое уже
   вставлен перевод (`source_chunk_set` в `translate`).
6. Ключ кэша не меняется: промпт тот же.

### 4.3 Журнал отброшенных правок

Сейчас строка «patch for paragraph 2 … keeping the original paragraph» не называет фрагмент.
На «A Drop of Corruption» из-за этого пришлось искать абзацы по обрывкам текста.

- Во все предупреждения `_apply_patches` и `_damages` добавить идентификатор фрагмента.
- Отброшенные правки записывать в `meta` строки кэша (`dropped_edits`: номер абзаца, причина,
  текст правки). Сейчас они теряются, и оценить ложное срабатывание задним числом нельзя.

### 4.4 Готово, когда

- [ ] на каждое правило есть тест на срабатывание и тест на похожую полезную правку;
- [ ] отдельным тестом проверена починка абзаца целиком (правило C её не трогает);
- [ ] отдельным тестом проверен английский недоперевод («began to burble»): его по-прежнему
      можно переводить;
- [ ] повтор на копиях кэшей даёт те же 20 срабатываний из §5.1 и ни одного на правках из §6.2;
- [ ] `proofread` и `style` ведут себя как прежде;
- [ ] `pytest` и `ruff` проходят, существующие тесты не ослаблены;
- [ ] обновлены `AI_PIPELINE.md`, раздел README про «patch for paragraph N», `CHANGELOG.md`.

## 5. Замер правил

Прогноз посчитан 2026-11-22 без обращений к модели: правила применены к правкам, уже лежащим в
кэшах шести книг. Правки, отброшенные прежними проверками, в кэш не попадают и здесь не видны.

### 5.2 Почему не для корректуры и стилистики

| Стадия | Правок | Срабатываний | Что это |
| --- | --- | --- | --- |
| `proofread` | 1450 | 12 | например, «Allons y» → «Allons-y», «буффинг» → «баффинг» |
| `style` | 2617 | 15 | в основном имя или термин заменены местоимением, чтобы убрать повтор |

Это их работа, отбрасывать такое нельзя.

### 5.3 Известные слабые места

- **Правило B** на списке из 16 фраз вымышленной и иностранной речи защищает 13. Две из трёх
  остальных закрывает правило A, «Nia nia» не закрывает ничто. Из 10 примеров английского
  недоперевода оно ошибочно защитило бы 2 («building services», «unfavorable position»). Среди
  настоящих правок сверки таких случаев не было.
- **Английский словарь вместо слов книги** не ошибается на этих 10 примерах и даёт те же 20
  срабатываний, но это новая зависимость или файл больше предела `check-added-large-files`.
  Поэтому выбран словарь самой книги.
- **Одно чужое слово** («nia», «bairana») правило B не защищает: оно неотличимо от недоперевода.
- **Правило C** сравнивает начала слов и не узнаёт производные: «Трансплантные ловушки» →
  «Ловушки-прививки» оно пропускает.
- **Имена и названия** латиницей (издательства, книги автора) сверка записывает кириллицей.
  Правила это не трогают, см. §9.

## 7. Этап 2. Промпт сверки

### 7.1 Изменения в `prompts/verify.md`, версия 4 → 5

Ниже смысл и черновая формулировка. Окончательную выбирает замер.

1. **Пункт 4 — только про недоперевод.**
   > Ordinary English left in the Russian text by mistake. Translate it. This is NOT: speech or
   > inscriptions in an invented or third language, which the original itself leaves untranslated
   > for its reader; a glossary term whose translation is written in Latin letters. Keep those
   > letter for letter, in Latin.
2. **Правило «never leave one standing»** получает то же исключение.
3. **Словарь.**
   > The translation column is the only allowed rendering: never swap it for a synonym. The notes
   > column explains a term and is never text to insert.
4. **Род имён:** перенести раздел «Gender of glossary names» из `prompts/proofread.md`.
5. **Запинки.**
   > Hesitations, stammers and broken words are content: keep them.
6. **Оригинал по номерам:** те же метки `===PARAGRAPH N===`, что у перевода.
7. **Правка не должна ломать русскую фразу.**
   > Re-read each corrected sentence: it must be grammatical and make sense on its own. If you
   > cannot fix it so, leave the paragraph out.

Осторожно с общими тормозами. В `13027b7` черновик с «most paragraphs need no change» сохранял все
правки стилиста, но перестал находить настоящие пропуски.

### 7.2 Как мерить

Запросы платные, поэтому **перед замером нужно согласие владельца**. Работать только на копиях
рабочих каталогов.

1. Перезапустить шлюз с коммитом `205c263`: до него шлюз терял повторяющиеся куски ответа и мог
   исказить замер.
2. 24 фрагмента «A Drop of Corruption», где лежат правки из §6:

   ```text
   ch12_c04 ch17_c01 ch18_c04 ch24_c02 ch25_c01 ch28_c01 ch29_c02 ch32_c01
   ch33_c01 ch35_c01 ch37_c02 ch39_c04 ch41_c01 ch42_c01 ch42_c02 ch49_c01
   ch53_c01 ch59_c01 ch60_c02 ch63_c02 ch66_c02 ch67_c02 ch68_c01 ch69_c02
   ```

   Вход — текст после `style`. Версии 4 и 5, по два запуска, уровень `low`. Это около 20 кредитов
   (0,20 на фрагмент).
3. Повторить проверку §4.5 от 2026-11-01: внесённые английские слова, потерянные «не», выпавшие
   предложения. Это ещё около 10 кредитов.
4. Считать **без проверок этапа 1**, иначе они скроют действие промпта.
5. Правки обеих версий перемешать и отдать арбитру вслепую, как в замере 2026-11-01. По числу
   правок качество не судить.

### 7.3 Готово, когда

- [ ] девиз и питийская речь целы в обоих запусках;
- [ ] замен термина словаря синонимом нет;
- [ ] вредных правок вне правил A–C хотя бы вдвое меньше, чем у версии 4;
- [ ] внесённых ошибок найдено не меньше, чем у версии 4 (английские слова: 11 из 11);
- [ ] правки стилиста не откатываются;
- [ ] версия промпта поднята, а в `CHANGELOG.md` сказано, что у книг в работе сверка будет
      выполнена и оплачена заново;
- [ ] результат замера записан в `docs/design/`.

## 8. Этап 3. Вторая модель, только при необходимости

Если после этапа 2 остаются правки, ломающие смысл, рассмотреть привратника по образцу `repair`:
модель получает оригинал, абзац до и после правки и отвечает «принять» или «отклонить». Это новая
платная работа на каждую книгу, поэтому сначала цена и замер, потом решение. В этой задаче этап 3
не реализуется.

## 9. Вопросы владельцу

1. **«трансплантант» в словаре серии — ошибка написания?** Системный словарь macOS знает только
   «трансплантат». Возможно, поэтому модель и уходит к «прививке». Исправление словаря меняет
   ключ кэша всех стадий, то есть книга в работе переводится заново.
2. **Названия издательств и книг автора на служебных страницах:** оставлять латиницей или
   переводить? Сейчас выходит по-разному: в одной книге есть и «Осквернённая чаша», и «Отравленная
   чаша». Встречается и прямая порча: «AD ASTRA» → «АД АСТРА», «Lindroth» → «Риндрот».
3. **Согласие на платный замер** этапа 2.

## 10. Риски

| Риск | Что делаем |
| --- | --- |
| Правило отбросит полезную правку на новой книге | правка записана в `dropped_edits`, предупреждение называет фрагмент |
| Вместе с вредной заменой пропадёт полезная часть той же правки | принято: так же работают остальные проверки правок |
| Сверка с новым промптом станет пассивной | условие §7.3 о внесённых ошибках |
| Новая версия промпта заново оплачивает сверку книг в работе | предупреждение в `CHANGELOG.md`, выпуск между книгами |
| Данные замера исчезнут: `work/` не в репозитории | примеры записаны в §6, перед `cache clear` нужна копия кэша |

## Приложение А. Определения правил

Этим кодом получены числа §5. Это определение поведения, а не готовый модуль: при переносе нужны
типы, имена и стиль проекта. `source`, `before`, `after` — видимый текст абзаца, `glossary` —
записи словаря, у которых есть перевод.

```python
import re
from collections import Counter
from difflib import SequenceMatcher

CYRILLIC_WORD = re.compile(r"[А-Яа-яЁё][А-Яа-яЁё-]*")
LATIN = re.compile(r"[A-Za-z]")
LATIN_RUN = re.compile(r"[A-Za-z][A-Za-z’'-]*(?: [A-Za-z][A-Za-z’'-]*)*")


def occurrences(text, phrase):
    return len(re.findall(rf"(?<!\w){re.escape(phrase)}(?!\w)", text))


def in_source(source, original):
    flags = 0 if original[:1].isupper() else re.I
    pattern = rf"(?<!\w){re.escape(original)}(?:s|es|’s|'s)?(?!\w)"
    return len(re.findall(pattern, source, flags))


def latin_term_lost(source, before, after, glossary):  # правило A
    for entry in glossary:
        term = entry["translation"]
        if not LATIN.search(term):
            continue
        needed = min(occurrences(before, term), in_source(source, entry["original"]))
        if occurrences(after, term) < needed:
            return entry["original"]
    return None


def book_vocabulary(source_paragraphs):  # для правила B, один раз на книгу
    seen = Counter()
    for text in source_paragraphs:
        seen.update(set(re.findall(r"\b[a-z]+\b", text)))
    return {word for word, paragraphs in seen.items() if paragraphs >= 2}


def is_foreign(phrase, vocabulary):
    words = phrase.split()
    if len(words) < 2 or not any(word[:1].islower() for word in words):
        return False  # одно слово или имя собственное
    unknown = sum(
        any(part not in vocabulary for part in re.findall(r"[a-z]+", word.lower()))
        for word in words
    )
    return unknown * 2 >= len(words)


def foreign_phrase_lost(source, before, after, vocabulary):  # правило B
    for phrase in LATIN_RUN.findall(before):
        if phrase in source and is_foreign(phrase, vocabulary):
            if occurrences(after, phrase) < occurrences(before, phrase):
                return phrase
    return None


def stem(word):
    word = word.lower().replace("ё", "е")
    return word[: max(4, len(word) - 2)] if len(word) > 4 else re.sub("[аеийоуыьэюя]$", "", word)


def glossary_term_lost(source, before, after, glossary):  # правило C
    if SequenceMatcher(None, before.split(), after.split(), False).ratio() < 0.5:
        return None  # абзац заменён целиком: так сверка чинит сдвиг
    old = [word.lower().replace("ё", "е") for word in CYRILLIC_WORD.findall(before)]
    new = [word.lower().replace("ё", "е") for word in CYRILLIC_WORD.findall(after)]
    for entry in glossary:
        if LATIN.search(entry["translation"]):
            continue
        stems = [stem(w) for w in CYRILLIC_WORD.findall(entry["translation"]) if len(w) > 2]
        wanted = in_source(source, entry["original"])
        if not stems or not wanted:
            continue
        count = lambda words: min(sum(w.startswith(s) for w in words) for s in stems)
        if count(new) < min(count(old), wanted):
            return entry["original"]
    return None
```
